## sportsdata

Free, open-source sports data for AI agents.

| Repo | What it is |
|---|---|
| [sportsdata-mcp](https://github.com/DanielTomaro13/sportsdata-mcp) | MCP server with 800+ sports-data tools across 64 providers. Ask your AI which bookmaker is paying more and get a real answer. |
| [sportsdata-agents](https://github.com/DanielTomaro13/sportsdata-agents) | Agentic sports-data workbench built on top of the MCP server. |
